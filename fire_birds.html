Fire effects on forest birds: guilds and species

  • Load data
  • Habitat lost to fire (Levins model)

Design. Forest zones only (NSW coast + escarpment, East Gippsland). Burnt = site at least 2 km inside the 2019–20 fire extent; unburnt = at least 2 km outside; sites within 2 km of the fire edge are dropped. Seven forest species in three guilds: ground (Superb Lyrebird, Eastern Yellow Robin) | understorey (shrub + midstorey) | canopy. Flame Robin is excluded (open-country bird). Eastern Yellow Robin is not in detections_long.csv, so its detections are built from birdata_raw.csv: detected = recorded in that survey.

Habitat lost to fire (Levins model)

Binomial GLMM (logit link) with one fire effect δ per guild (the burnt × after interaction); each species has its own baseline, before/after change, burnt/unburnt difference and season effect; random intercepts for site and site × species. In Levins’ model with habitat destruction, P = 1 − v − e/c, so the share of patches lost to fire is v = P without fire − P with fire, both predicted for burnt sites after the fire. The unburnt sites give e/c = 1 − P*.

library(lme4)
ctrl <- glmerControl(optimizer = "bobyqa", optCtrl = list(maxfun = 1e5))
base <- "detected ~ species * after + species * burnt + species:season + (1 | site) + (1 | site:species)"
m2 <- glmer(as.formula(paste(base, "+ grp:burnt:after")), d, binomial, control = ctrl, nAGQ = 0)

# coefficient name for guild g × burnt × after (any order of the parts)
gterm <- sapply(glev, function(g) {
  nms <- names(fixef(m2))
  nms[vapply(strsplit(nms, ":"), function(x) length(x) == 3 && setequal(x, c(paste0("grp", g), "burnt", "after")), TRUE)]
})
B <- fixef(m2); V <- as.matrix(vcov(m2))
ba <- d$burnt == 1 & d$after == 1
eta <- predict(m2, re.form = NA)[ba]               # linear predictor, burnt sites after the fire
set.seed(1)
draws <- MASS::mvrnorm(2000, B[gterm], V[gterm, gterm])   # uncertainty in the guild δ

# P* = 1 - e/c (no fire); fire adds v:  P = 1 - v - e/c
#   buffer_used = v / P*             share of the way to the extinction threshold (v = P*)
#   c_needed    = (e/c) / (e/c - v)  factor by which colonisation must rise to restore P*
#   e_needed    = 1 - v / (e/c)      factor by which local extinction must fall to restore P*
mgmt_one <- function(g, delta) {
  i <- d$grp[ba] == g
  Pstar <- mean(plogis(eta[i] - B[[gterm[[g]]]]))
  v <- Pstar - mean(plogis(eta[i] - B[[gterm[[g]]]] + delta))
  ec <- 1 - Pstar
  c(Pstar = Pstar, v = v, e_over_c = ec, buffer_used = v / Pstar, c_needed = ec / (ec - v), e_needed = 1 - v / ec)
}
mgmt <- bind_rows(lapply(glev, function(g) {
  est  <- mgmt_one(g, B[[gterm[[g]]]])
  sims <- t(apply(draws, 1, function(x) mgmt_one(g, x[[gterm[[g]]]])))
  data.frame(guild = g, quantity = names(est), est = est,
             lo = apply(sims, 2, quantile, 0.025), hi = apply(sims, 2, quantile, 0.975))
}))
